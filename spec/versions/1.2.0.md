## Verification

Production smoke on 2026-11-16 in real host Chromium, browser egress through the local proxy:
synthetic username login; exactly one Run persisted across reload; Settings navigation and the
timezone/language controls usable; the in-app print dialog contained the synthetic username
with `window.print` calls still zero; About rendered 1.2.0. The first attempt of this smoke
round failed on a harness fault (calling `response.body()` on a redirect), not on the product;
after the harness was fixed all six criteria passed.
