# 2.1.0 — repository structure converted to the project standard

Status: current. Specification-only version: no artifact byte changes, so the app keeps showing
2.0.1.

## Scope

The repository now follows the ASIDE project standard. Everything that describes the repository
lives under `spec/`; the root `AGENTS.md` is a pointer. Shape:

```
AGENTS.md                 one line: read spec/AGENTS.md first
README.md                 what the project is and how to run it
spec/AGENTS.md            operating guide: reading order, language, commands, boundaries
spec/facts/<module>.md    current truth, rewritten in place
spec/versions/README.md   the ladder
spec/versions/X.Y.Z.md    one delivery record per version
spec/backlog/README.md    deferred work and questions, with the reason
spec/contract/            schemas others must obey (the PostgreSQL DDL)
```

Retired: the numbered decision ledger, the single version catalogue, two roadmap files, the
separate `spec/README.md` ownership table and `spec/WORKFLOW.md`.

Owner decisions of 2026-11-17 completed the same version:

- the front page keeps several languages (`README.md` plus `README_CN.md`); `spec/` stays English;
- `archived/` (retired self-host files) and `design/` (pre-rebuild design material) were deleted;
- 2.0.1 is **accepted** — the owner used the deployed build — and the ladder says so;
- historic version tags were back-filled on the commits the ladder had recorded.

## Decisions

- **The decision ledger is folded into the facts, not archived.** Each ADR's live rule moved into
  the facts module that owns it; the map below is the proof nothing was dropped.
- **`main`-only branching is superseded.** The earlier rule ("one environment, so `develop →
  testing → main` adds ceremony") gave way to the collaboration contract: `develop`, `testing`,
  `main`, fast-forward promotion, `dev/*` merged into `develop` first, `version/X.Y.Z` tags on
  recorded commits only.
- **A structure change is a version.** The ladder previously treated documentation-only pushes as
  "not a version". Under the standard every change belongs to a version; 2.1.0 is recorded as a
  specification version with no artifact change, and the ladder says so in the row itself rather
  than pretending the About label moved.
- **Stale target-voice facts were corrected, not carried.** `facts/architecture.md` and
  `facts/i18n.md` described the pre-rebuild target (XML locales, `localStorage`, "current
  structure: 45 files"). They now describe what ships.
